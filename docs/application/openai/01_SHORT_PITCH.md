# 短い説明

GUI-Shell は、Agent と local Runtime を操作する Windows-first desktop Runtime Operation Shell である。Schema、conformance test、Flutter UI、Rust broker を通じて、権限、Approval、Audit、Recovery、証拠の境界を検査可能にする。

人間と実装 Agent の双方が読める責任基盤として設計するが、LLM を権限源にはしない。

本 repository は、非プログラマーが1か月未満の兼業作業でLLMへ指示し、責任境界を持つ software repository を構築・文書化・検証・公開した、限定された process demonstration でもある。これは一般的能力、完成製品、または外部 endorsement の主張ではない。
