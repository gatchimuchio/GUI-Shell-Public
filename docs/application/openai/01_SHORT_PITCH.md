# Short Pitch

GUI-Shell is a Windows-first desktop Runtime Operation Shell for agent and local-runtime operations. It makes authority, approval, audit, recovery, and evidence boundaries inspectable through schemas, conformance tests, a Flutter UI, and a Rust broker.

It is designed for review by humans and implementation agents without treating the LLM as an authority source.

The repository is also a process demonstration: a non-programmer / non-software developer directed an LLM to build, document, validate, and publicly launch a responsibility-bounded software repository in less than one month of part-time work.
