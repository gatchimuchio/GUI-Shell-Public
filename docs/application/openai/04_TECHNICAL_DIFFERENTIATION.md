# Technical Differentiation

GUI-Shell is differentiated by its contract-first and evidence-first structure:

- JSON Schema contracts for runtime, adapter, approval, audit, recovery, broker, and agent surfaces
- conformance tests for authority stripping and content exposure
- broker IPC with replay rejection and fail-closed behavior
- explicit release blocker registry
- source manifest validation
- sanitized Windows installed-path evidence summaries

The project is not a terminal wrapper and not a BLUE-TANUKI-specific UI.
